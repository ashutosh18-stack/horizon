# 🏡 Horizon Properties – Luxury Real Estate Website

A modern, premium real estate consultancy website designed to deliver an elegant property browsing experience with responsive layouts, interactive elements, and a luxury-inspired UI/UX.

### ✨ Key Features
- Modern and premium responsive UI/UX
- Luxury residential and commercial property listings
- Property search with location and category filters
- Featured villas, apartments, penthouses, and commercial properties
- Property buying, renting, and commercial search options
- Real estate services and investment advisory sections
- Client testimonials and company information
- Consultation and contact sections
- Mobile-friendly design and smooth navigation
